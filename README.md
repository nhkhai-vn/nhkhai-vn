# Staff engineer

I build products from zero to production and take responsibility for the whole system decision — from architecture and backend services to frontend, infrastructure, and production operations.

I enjoy working on ambiguous problems where there isn't already a team or architecture waiting to be used.

## 🛠️ What I do

* 🧠 Turn ideas and rough requirements into production systems, making the architecture and technology decisions along the way
* 🧩 Own systems end to end: architecture, backend, frontend, infrastructure, deployment, and production operations
* 🤖 Build LLM systems that do real work — agent orchestration, function calling, RAG, structured workflows, and multi-step document generation
* 🏢 Design multi-tenant SaaS platforms with authentication, authorization, subscription billing, usage limits, and admin tooling
* 🔎 Build data and search systems — ingestion pipelines, scheduled workloads, retrieval, indexing, and relevance tuning
* ☁️ Design and operate production cloud infrastructure, including CI/CD, secrets, service identity, observability, and staging-to-production delivery
* 🔐 Build with security, reliability, maintainability, and operational simplicity in mind
* ✨ Keep codebases healthy through clear boundaries, pragmatic architecture, small reviewable changes, and AI-assisted development
